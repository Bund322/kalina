# 02 — Мастера из JSON и страницы мастеров

Status: ready-for-agent
Blocked by: 01

## Что сделать

- `src/data/masters.json` со схемой из ТЗ (`slug`, имя, фото, направление `tattoo|piercing|both`, стили,
  описание, `telegram?`, `instagram?`, `works: [{ photo, caption? }]`, до 9 работ). Схему проверять при
  сборке (zod / content collections) — понятная ошибка, если поле пропущено или работ больше 9.
- Фото — `src/content/masters/<slug>/`; сгенерировать заглушки в цветах студии с итоговыми именами
  для 3 примерных мастеров.
- Страница `/masters/<slug>`: фото, имя, направление, стили, описание, портфолио 3×3 (подпись при наведении),
  ссылки мастера или общая кнопка записи студии.
- Секция «Мастера» на главной — из JSON, карточки ведут на страницы мастеров.
- Фото через `astro:assets` (WebP, несколько размеров, lazy).

## Готово, когда

- Добавление/удаление мастера в JSON (+ папка с фото) после сборки добавляет/убирает его страницу и карточку.
