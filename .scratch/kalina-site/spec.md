# ТЗ: сайт-визитка студии «Калина»

Status: ready-for-agent

## Цель

Превратить одностраничный макет `Калина Tattoo Studio.html` в полноценный сайт-визитку тату- и
пирсинг-студии: страницы мастеров, интерактивная 3D-голова с зонами пирсинга, интерактивный 3D-манекен
с картой боли для тату. Контент правится через JSON-файлы и папки с фото, без админки.

## Стек и инфраструктура

- **Astro** в статическом режиме (`output: 'static'`), 3D — **three.js** (клиентские скрипты).
- Визуальный стиль, палитра, шрифты, анимации — из макета (см. `CLAUDE.md`). Макет переносится в
  `docs/mockup/` как эталон.
- Фото хранятся в репозитории; при сборке Astro (`astro:assets`) сжимает их в WebP нескольких размеров,
  картинки грузятся лениво. На хостинг уходит только `dist/`, сайт к GitHub не обращается.
- Хостинг — обычный виртуальный (Timeweb или SprintHost, пока не выбран). Сервер Node.js не нужен.
- Git: `origin` = `git@github.com:Bund322/kalina.git`. Разработка — `dev_seits`, на сайт попадает `main`.
- Автодеплой: GitHub Actions на push в `main` собирает сайт и заливает `dist/` по FTP/SFTP.
  До выбора хостинга workflow выключен; секреты описаны в README. Запасной вариант — ручная заливка `dist/`.

## Страницы

### `/` — главная
По макету: hero, бегущая строка, галерея «Работы», мастера, прайс, уход, запись, подвал.
- Галерея собирается из работ всех мастеров; фильтр «Все / Тату / Пирсинг» — по направлению мастера.
  На плитке — подпись работы (если есть) и имя мастера со ссылкой на его страницу.
- Секция «Мастера» — карточки из `masters.json`, ведут на `/masters/<slug>`.
- Тизеры «Выбрать прокол на модели» → `/piercing` и «Карта боли» → `/tattoo`.
- Пункты навигации ведут и на новые страницы.

### `/masters/<slug>` — страница мастера
Имя, фото, направление (тату / пирсинг / оба), стили-теги, описание (2–3 абзаца), портфолио до 9 работ
сеткой 3×3. Ссылки Telegram/Instagram необязательны — если их нет, показывается общая кнопка записи студии.
Первая работа мастера — его обложка в общей галерее.

### `/piercing` — 3D-голова
- 3D-голова, которую можно вращать (мышь, тач); масштаб ограничен разумными пределами.
- Модель — готовая, лицензия CC0 (допустим CC-BY с указанием автора в подвале). Уши должны быть
  детализированы. Материал матовый, «скульптурный», цвет `--sand-lt`; точки проколов — `--brick`.
- Точки проколов:
  - **ухо**: мочка, хеликс, форвард-хеликс, флэт, трагус, рук, ложный рук, конч, дейс, индастриал, пина, снаг;
  - **нос**: крыло носа, септум, бридж;
  - **лицо**: бровь, лабрет, вертикальный лабрет, симметрия губ, медуза, монро, мадонна;
  - **язык и смайл** — одна точка «внутри рта» на губах, по нажатию — выбор «Язык / Смайл».
- **Попап**: название, короткое описание, 2–3 фото, цена «от …», время заживления. Кнопки записи нет.
  На телефоне — выезжает снизу (bottom sheet), на компьютере — карточка сбоку, модель остаётся видна.
- Под моделью — блок «Проколы на теле»: пупок и соски карточками, по нажатию тот же попап.
- Ниже — прайс и уход за проколами.
- Другие проколы в рамках задачи не рассматриваются.

### `/tattoo` — 3D-манекен
- Один нейтральный (андрогинный) манекен, вращается как голова.
- Зоны — целые участки тела, подсвечиваются при наведении/нажатии: голова/лицо, шея, грудь, живот,
  рёбра, спина верх/низ, поясница, плечо, предплечье, локоть, запястье, кисть/пальцы, ягодицы, бедро,
  колено, голень, щиколотка, стопа (точный список уточняется при реализации, левое/правое не различаем).
- **Попап**: название зоны, шкала боли 1–5 (ягоды в фирменном цвете), 1–2 предложения «почему так»,
  совет. Тексты пишет исполнитель, заказчик потом правит.
- Переключатель «Показать карту боли» раскрашивает всю модель от светлого (1) к кирпичному (5).
- Ниже — прайс и уход за тату.

### Общее для 3D-страниц
- Пока модель грузится — индикатор загрузки; без WebGL — список зон кнопками с тем же попапом.
- Зоны дублируются доступным списком (клавиатура, скринридер).
- `prefers-reduced-motion` отключает автоповорот и анимации попапа.

## Контент и данные

| Файл | Содержимое |
| --- | --- |
| `src/data/masters.json` | мастера: `slug`, имя, фото, направление, стили, описание, ссылки, `works: [{ photo, caption? }]` |
| `src/data/piercings.json` | проколы: `id`, название, группа, описание, цена, заживление, координаты точки на модели, список фото |
| `src/data/tattoo-zones.json` | зоны: `id`, название, имя участка меша, боль 1–5, пояснение, совет |
| `src/data/studio.json` | прайс, контакты, часы работы, ссылки Telegram/WhatsApp |

- Фото мастеров: `src/content/masters/<slug>/` (фото мастера + `work-N.jpg`), в JSON — только имя файла.
- Фото проколов: `src/content/piercings/<id>-N.jpg`.
- Все фото на старте — заглушки в цветах студии с итоговыми именами файлов: замена — подложить файл с тем же именем.
- README: как добавить/удалить мастера, заменить фото и тексты, задеплоить.

## Вне рамок

Админка, учётные записи, онлайн-запись и кнопка «Записаться на этот прокол», переключатель пола
манекена, проколы сверх перечисленных, тёмная тема, мультиязычность.
